## 5. 关键决策与理由

1. **用文献结构替换演示结构**：原 baseline 是 50 nm / krad(SiO2) 的无来源演示，无法满足"可追溯"。
2. **数字化走矢量路径**：两篇论文的图都是矢量，可精确复算，避免手抄读数。
3. **迁移率用模型反演**：Gm 同时受阈值/摆幅漂移影响，闭式强反型公式会把偏差错误塞进 μ。
4. **保留单调幂律并显式报告 200 krad 摆幅谷的残差**：论文把该现象归因于退火（两阶段机制），无额外数据支撑时不加三次项。
5. **n 型保持显式假设**：两篇文献都没有 n 型 TID 数据，因此把"n/p 比"作为带区间的假设参数并做区间扫描。
6. **参数绑定结构**：跨文献证据表明指数随结构变化 0.23–0.85，报告与代码都声明该配置只对 Cui 顶栅有效。

## 6. 已知局限

1. **无 n 型 TID 数据** —— 反相器结论条件于 n/p = 1.0（区间 0.5–1.5）。
2. **只有三个指标、没有全曲线** —— 模型形状（EKV 平滑）未被数据检验。
3. **200 krad 摆幅谷** —— 残差 27.7 mV/dec。
4. **双极性与接触** —— 论文正栅压侧电流回升未建模。
5. **跨结构不可移植** —— 迁移误差 2–5 倍。
6. **无器件离散 / 剂量率 / 退火项**。
7. **TCAD 未接入本链条**（tcad/cntfet/topgate/ 仍是参数补齐阶段）。
