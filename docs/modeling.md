# 基线模型与单位约定

## 1. 模型定位

v0.1 采用“剂量—陷阱电荷—紧凑电学参数—电路静态响应”的等效链路，用于验证数据流、符号方向、指标提取和实验设计。

所有内部计算采用 SI 单位；配置中的几何量使用 `um`、`nm`，剂量系数使用 `C/cm2/krad`。默认剂量单位为 `krad(SiO2)`；与 `krad(Si)` 联合分析前，先完成有材料依据的剂量换算。

## 2. 总剂量映射

对剂量 `D`（krad）：

```text
Qot(D) = k_ot * D
Qit(D) = k_it * D
ΔVq    = (Qot + Qit) / Cox
Cox    = ε0 * εr / tox
```

对正陷阱电荷：

```text
nFET: Vth,n(D) = Vth,n0 - ΔVq
pFET: |Vth,p(D)| = |Vth,p0| + ΔVq
```

这里 `Vth,p` 在代码中以正的阈值幅值表示。迁移率和斜率因子为：

```text
μ(D) = μ0 / (1 + αμ * D)
n(D) = n0 + αn * D
```

线性剂量律作为初值。实测出现饱和、非单调或退火效应时，采用分段或饱和模型，并报告适用范围。

## 3. 电流模型

代码采用平滑的 EKV 风格等效表达式：

```text
Ut   = kB * T / q
Vs   = 2 * n * Ut
Vov  = Vs * ln(1 + exp((|Vgs| - |Vth|) / Vs))
Vde  = Vov * (1 - exp(-|Vds| / Vov))
Id   = 0.5 * μ * Cox * (W/L) * Vov * Vde * (1 + λ * |Vds|)
```

该式保证零漏压时电流为零，并平滑连接亚阈值和强反型区域，适用于流程与电路指标验证。

## 4. 反相器求解

每个输入电压下求解静态电流平衡：

```text
Id,n(Vin, Vout) = Id,p(VDD - Vin, VDD - Vout)
```

- `VOL = Vout(Vin=VDD)`；`VOH = Vout(Vin=0)`；
- `VIL`、`VIH` 取 `|dVout/dVin|=1` 的前后交点；
- `VM` 取 `Vout=Vin` 的交点；
- `NML=VIL-VOL`，`NMH=VOH-VIH`。

交点提取失败时，结果记为 `NaN`；v0.2 起 `solve_inverter` 同时发出显式警告。后续增加网格收敛检查。

## 5. 标定要求

至少使用两个非零剂量点及一个零剂量点。推荐顺序：

1. 零剂量下拟合几何、有效迁移率、初始阈值和接触/寄生参数；
2. 固定零剂量输运参数，用多剂量转移曲线拟合 `Qot`、`Qit`；
3. 用输出曲线或跨导退化约束迁移率模型；
4. 留出至少一个剂量点做验证，不参与拟合；
5. 报告剂量单位、辐照偏置、剂量率、温度、测量等待时间和退火条件。

## 6. 标定方法（v0.2 起）

`cnt-tid calibrate` 按以下步骤从 `data/calibration_template.csv` 格式的数据拟合剂量系数：

1. **单曲线拟合**：对每个（器件, 剂量）点的转移曲线，用 `scipy.optimize.least_squares` 以对数电流残差拟合紧凑模型的 `(Vth, μ, n)`，拟合出的就是该剂量下的退化后参数，不再叠加剂量律；
2. **总电荷斜率**：对 `ΔVth(D)` 做线性拟合，`k_total = |slope| · Cox`；n 器件阈值随剂量下降、p 器件阈值幅值上升，符号在拟合中取绝对值；
3. **Qot/Qit 拆分（启发式）**：由摆幅退化 `dn/dD` 折算 `Qit ~ (dn/dD) · Cox`，并以总电荷为上界截断，其余归 `Qot`。该拆分用于紧凑参数估计；两种陷阱的独立识别需要额外测量，报告中保留方法说明；
4. **迁移率退化**：对 `1/μ(D)` 线性拟合，`αμ = slope/intercept`；
5. **留一剂量点验证**：逐点留出非零剂量点，用其余点预测被留点的阈值漂移并报告残差；拟合误差不等于预测误差。

数据要求：单一剂量单位、零剂量参考曲线、至少两个不同非零剂量点、每条曲线不少于 10 个正电流点、端电压与电流均为正幅值。

## 7. 敏感性分析方法（v0.2 起）

`cnt-tid sensitivity` 采用一次一因子（OAT）相对扰动：对每个选中参数施加 ±`magnitude`（默认 10%）扰动，保持其余参数不变，在每个剂量点重解反相器并记录 `VM`、`NML`、`NMH` 及 n/p 阈值漂移的变化。输出：

- `sensitivity_per_unit`：`dM/dp`，指标对参数绝对值的平均灵敏度；
- `mean_normalized_sensitivity`：`(ΔM/M)/(Δp/p)` 在各剂量点的均值（弹性），基线接近 0 的指标该值为 `NaN`；
- 龙卷风图在最大剂量处绘制三个静态指标的 ± 扰动弹性。

OAT 只覆盖局部、一阶效应，不捕捉参数间交互作用；如需交互项应改用 Morris 筛选或方差分解。

## 8. 几何实验矩阵与可追溯性（v0.3 起）

`cnt-tid matrix` 对栅氧厚度倍率和栅长倍率做笛卡尔积，默认均为 `(0.8, 1.0, 1.2)`。同一倍率同步应用于 n/p 器件，并在每个几何场景下重新执行全部剂量点，用于紧凑模型的几何敏感性分析。

每个场景保存在独立目录，包含原始转移曲线、VTC、指标摘要、完整有效配置和配置 SHA-256。矩阵清单显式记录失败场景，失败目录中的 `failure.txt` 保存堆栈，求解警告保存为 `warnings.txt`。非有限的 `VM/VIL/VIH/NML/NMH` 会判定为失败，不作为有效结果混入汇总。矩阵热图只展示最大剂量处的静态电路指标，缺失场景标记为 `failed`。

在当前模型中，驱动电流含共同的 `W/L` 因子，而理想反相器静态工作点只取决于 n/p 电流之比。因此同步缩放两种器件的栅长会改变器件电流幅值，但不会改变 `VM` 或噪声容限；热图中的等值列是该简化模型的必然结果。研究栅长相关的电路退化需要引入经数据约束的非对称几何、短沟道效应或寄生模型。

配置指纹对规范化后的有效配置计算，与原始 TOML 的空格和字段顺序无关。原始输入文件及其校验和另行归档，用于文件级追溯。

## 9. 结果适用范围

当前结果用于比较模型趋势和开发分析流程。最大耐受剂量、在轨寿命、器件失效概率和抗辐射加固效果的定量评估以 TCAD/实验标定为前提。

## 10. Cui 2023 文献器件的适用范围

Cui 2023 研究的是 4 µm 栅长、30 µm 宽度的顶栅 P 型 CNT 网络器件，顶栅 Y2O3/HfO2 总厚度为 10 nm，埋氧为 280 nm，剂量点为 0–3000 krad(Si)。这些条件与本文档前面的 50 nm、`krad(SiO2)` 演示 baseline 分别记录，并按各自的实验条件分析。

W-2024.09 没有内置 CNT 材料，`tcad/cntfet/topgate/` 因此采用二维有效半导体和串联等效顶栅介质。模型重点描述静电、有效输运与等效陷阱响应；CNT 手性分布、网络结电阻、一维量子输运和吸附物动态列为后续扩展。论文中亚阈值摆幅先下降后上升（200 krad 谷），自 v0.7.0 起由两阶段界面密度律（生成幂律 − 饱和退火）描述，见第 11 节。

模板中的固定电荷是作用于 `CNTNetwork/TopDielectric` 界面的等效面电荷（cm-2），其数值由剂量标定确定。零剂量标定和独立剂量点验证完成前，所有结果保持 `awaiting_user_digitization_and_assumptions` 或 `illustrative_literature` 状态。

## 11. P0 扩展（v0.5.0 / v0.7.0）

P0 在保持上述链路的前提下增加可标定扩展，均可通过配置开关关闭：

1. **剂量幂律** `dose_exponent`：Q(D) = k·D^p。p = 1 退化为原线性律；P0 对 Cui 2023 数据的拟合结果为 p = 0.482（亚线性）。系数单位随之为 `C/cm2/krad^p`。
2. **摆幅由界面密度驱动，两阶段律** `slope_factor_from_qit`（v0.7.0）：n(D) = n₀ + N_it,net(D)/Cox，对应论文 Eq.(3)。开启后 `slope_factor_per_krad` 必须为 0。净密度为

   `N_it,net(D) = qit_density_slope·D^p − qit_anneal_c_cm2·(1 − exp(−D/qit_anneal_dose_krad))`

   生成项与阈值通道共用 p；退火项钝化预存界面态、在摆幅通道产生 200 krad 谷（Cui 2023 Figure 3c）。**退火项只进入摆幅通道**：阈值只看 (qot + qit)·D^p 的 charged 电荷通道，与密度通道解耦（摆幅感应陷阱密度，阈值感应净电荷；被钝化的预存态近乎电中性）。三个密度字段全为零时回落到旧行为（charged 通道兼任密度）。
3. **反相器轨钳位**：电流平衡方程在 [0, VDD] 内无解时，输出钉在 0 或 VDD，而不是抛异常。高剂量下 n 管失去关断能力时即为该情形。

标定方法（`src/cnt_tid/metric_calibration.py`）：

- 从数字化指标反推：ΔVth → Q_tot；SS → N_it,net（可负，正是谷）；Q_ot = Q_tot − Q_it记账拆分并强制为正；
- 摆幅密度通道按数字化误差棒加权拟合两阶段律（误差棒下限 3 mV/dec），目标面多峰，采用确定性起点网格做多起点拟合；
- 迁移率在探针条件（VDS = 0.1 V，|VGS| 0…2 V）下**反演紧凑模型**得到，αμ 再对模型 Gm 做一维拟合，避免把阈值/摆幅漂移错误归入迁移率；
- 验证分三层：逐点残差、留一剂量点预测、±10 % OAT 弹性。

已知偏差（v0.7.0 更新）：200 krad 谷由两阶段律复现，摆幅最大残差从 27.7 降至 17.9 mV/dec（≈1.1σ），六个剂量点全部落在数字化误差棒的 1.1σ 内；模型谷底跨 200–500 krad，比实测宽一个格点；退火动力学在首个实测剂量点之前不可辨识，D_a 为加权全局最优而非唯一解。

**量纲约定提醒**：Q_it 是"摆幅等效界面电荷"（Cox·Δn），与 Dit 的严格换算需要额外的界面电容测量；用于紧凑模型参数化是自洽的，但不应当作陷阱谱的绝对密度。

## 12. 准静态环振模型（v0.8.0）

紧凑模型没有瞬态求解器，电路级频率退化采用标准准静态一阶模型（`src/cnt_tid/ringosc.py`）：

1. **负载电容**：C_L = Cox·W·L，即下一级的栅电容；线电容与结电容忽略（对 4 µm 栅长、2 V 电源的论文器件，栅电容 1.59 pF 占主导）。
2. **50 % 传播延迟**：t_pd = (t_phl + t_plh)/2，每一支为 C_L·∫₀^{VDD/2} dV/I，电流取剂量漂移后的器件态。正幅值约定下两支积分表达式相同（n：Vgs=VDD、Vds 从 VDD 降到 VDD/2；p：Vsg=VDD、Vsd 同步下降），不对称性完全由两管的漂移后参数携带。模型电流严格线性于 μ，故 t_pd ∝ 1/μ 是精确性质（有单元测试锁定）。
3. **振荡频率**：f_osc = 1/(2·N·t_pd)，N 为奇数级数（registry `sim.ro_stages`，默认 11）。
4. **功耗**：动态 = N·C_L·VDD²·f（每个节点每周期摆动一次）；静态 = VDD·两级固定输入（Vin=0 与 Vin=VDD）工作点直通电流的平均值。直通电流由 `circuit.static_operating_current` 的电流平衡方程求解——零剂量时是亚阈漏电，n 管阈值过 0 后跳变为无法关断的直通电流。

**适用范围**：这是趋势模型，不是瞬态电路仿真器。它回答"频率/功耗随剂量怎么走、哪个机制主导"，不能给出开关能量的精确分解或波形；后者需要 TCAD 混合模式瞬态（P1-5b）。C_L 忽略线/结电容在小规模环中误差约 10–30 %，若做版图级预测必须补上。
