# 仿真与标定矩阵

## P0 器件矩阵

| 因子 | 建议水平 | 备注 |
| --- | --- | --- |
| 剂量 | 0、100、300、500、1000 krad(SiO2) | 演示配置；实测需保持材料剂量单位一致 |
| 器件极性 | n、p | 两者分开标定，不默认完全对称 |
| 辐照偏置 | OFF、ON | 有偏置历史数据后再纳入定量模型 |
| 漏压 | 低场、高场（如 0.05 V、VDD） | 区分线性与饱和区退化 |
| 温度 | 300 K | 其他温度列为 P1 |
| 栅氧厚度 | 标称值；敏感性 ±20% | 检验 `ΔV ∝ Q/Cox` 的影响 |
| 栅长 | 标称值；敏感性 ±20% | 短沟道效应需由 TCAD/数据约束 |

当前可用以下命令执行紧凑模型的 3×3 几何矩阵；每个场景仍包含配置中的全部剂量点：

```bash
cnt-tid matrix --config configs/baseline.toml --output results/matrix \
    --oxide-scales 0.8 1.0 1.2 --length-scales 0.8 1.0 1.2
```

该命令同步缩放 n/p 器件，不代表已完成非对称器件或短沟道效应标定。逐场景状态和失败日志见 `matrix_manifest.csv` 与 `runs/<场景>/failure.txt`。

## 每个剂量点必须保存

- `Id–Vg` 原始曲线及扫描方向；
- 偏置、剂量率、累积剂量、温度与测量时间；
- `Vth`、`Ioff`、`Ion`、最大跨导和亚阈值摆幅；
- 求解器收敛状态或实验数据质量标记；
- 配置版本与输入数据校验和。

## 电路矩阵

当前电路研究聚焦静态反相器：输入从 0 扫描至 VDD，输出无负载或使用固定小电容仅用于数值稳定。提取 `VM`、`VIL`、`VIH`、`VOL`、`VOH`、`NML`、`NMH`。动态延迟和功耗列入下一阶段。
