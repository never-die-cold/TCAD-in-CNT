## 每日工程规则

- 原始数据只读保存，处理结果由脚本生成；
- 每次运行保存完整配置、模型版本、剂量单位和标定状态；
- TCAD 不收敛点保留日志，不静默插值成“成功”；
- 图上的每条曲线都能追溯到配置和输入数据；
- 未标定结果统一标记 `illustrative_uncalibrated`。

## 风险与降级路径

| 风险 | 降级方案 |
| --- | --- |
| 无 Sentaurus 许可或 CNT 材料参数不足 | 保留紧凑模型主线，明确为等效仿真，提交 TCAD 接口与参数需求 |
| 缺少多剂量实验数据 | 做文献参数敏感性和不确定性区间，不宣称预测精度 |
| 三维量子模型两周内不收敛 | 降到二维静电/等效固定电荷模型，记录近似与误差 |
| 电路混合模式成本过高 | 使用经 TCAD 曲线标定的紧凑模型进行静态电路分析 |
