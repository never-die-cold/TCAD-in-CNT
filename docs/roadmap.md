# 两周研发计划（10 个工作日）

## 交付目标

最小可结项成果（P0）：一种明确结构的 CNTFET、一组可追溯的 TID 参数、器件与反相器剂量扫描、标定/敏感性分析、可复现代码与结项图表。

扩展成果（P1）：混合模式 TCAD、环形振荡器频率退化、更多标准单元。P1 不得占用 P0 的标定与验证时间。

| 日程 | 任务 | 当日验收 |
| --- | --- | --- |
| D1 | 冻结器件结构、剂量单位、偏置条件和输出指标；建立仓库 | 配置、基线流程、测试和文档可运行 |
| D2 | 建立顶栅/GAA 几何与网格；收集零剂量数据 | 网格文件、参数表、零剂量曲线对齐计划 |
| D3 | 校准零剂量静电与输运；检查网格收敛 | 至少一条 `Id–Vg` 曲线达到约定误差 |
| D4 | 建立 `Qot/Qit` 或 TCAD 辐射陷阱模型 | 多剂量阈值漂移方向和量级合理 |
| D5 | 执行器件剂量 × 偏置 × 几何矩阵 | 原始曲线、提取指标、失败点日志齐全 |
| D6 | 构建互补反相器，完成 VTC/增益/噪声容限 | 器件到电路联合结果与物理解释 |
| D7 | 做参数敏感性和独立剂量点验证 | 给出主控参数、误差和适用范围 |
| D8 | 冻结 P0 结果；可选开展混合模式或环形振荡器 | P0 图表定稿，P1 单独标识 |
| D9 | 整理结项报告、方法、局限和复现说明 | 从干净环境一键重现主要结果 |
| D10 | 代码审查、数据归档、版本发布与答辩材料 | 标签版本、归档包、最终图表和演示 |

## 每日工程规则

- 原始数据只读保存，处理结果由脚本生成；
- 每次运行保存完整配置、模型版本、剂量单位和标定状态；
- TCAD 不收敛点保留日志，不静默插值成“成功”；
- 图上的每条曲线都能追溯到配置和输入数据；
- 未标定结果统一标记 `illustrative_uncalibrated`。

## 风险与降级路径

| 风险 | 降级方案 |
| --- | --- |
| 无 Sentaurus 许可或 CNT 材料参数不足 | 保留紧凑模型主线，明确为等效仿真，提交 TCAD 接口与参数需求 |
| 缺少多剂量实验数据 | 做文献参数敏感性和不确定性区间，不宣称预测精度 |
| 三维量子模型两周内不收敛 | 降到二维静电/等效固定电荷模型，记录近似与误差 |
| 电路混合模式成本过高 | 使用经 TCAD 曲线标定的紧凑模型进行静态电路分析 |
